# Process Agent Fragments

Concise instructions for repeatable agent workflows such as planning, verification, review, migrations, and releases.

## Fragments

- `readme-files.md` defines the scope and content expectations for repository README files and
  their translations.
- `task-estimation.md` defines the required range and basis for engineering task estimates.
- `testing.md` defines when automated tests are worth keeping and distinguishes behavioral tests,
  defect regressions, appropriate test boundaries, one-time verification, and static enforcement.
- `verification.md` defines how to use project checks, report evidence, and inspect commands before
  granting them agent-trusted status.
