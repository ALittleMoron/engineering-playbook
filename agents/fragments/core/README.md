# Core Agent Fragments

Candidates for universal instructions: autonomy boundaries, change safety, communication, and result verification. Project- and technology-specific guidance does not belong here.

## Fragments

- `authority-boundaries.md` defines when agents may inspect or change state without additional confirmation.
- `guidance-maintenance.md` defines how reusable agent guidance is proposed, scoped, and approved.
- `todo-files.md` separates finite tasks from durable guidance.
