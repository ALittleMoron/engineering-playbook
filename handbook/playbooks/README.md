# Playbooks

Finite, repeatable procedures for planning, implementation, debugging, review, migrations, releases, and incident response. Each playbook should define its entry conditions, steps, and completion criteria.

## Playbooks

- [Testing database migrations](database-migrations.md) covers representative existing data and
  independence from current ORM models.
- [Temporary release flags](temporary-feature-flags.md) covers safe defaults, both behavior paths,
  failure fallback, and removal.
